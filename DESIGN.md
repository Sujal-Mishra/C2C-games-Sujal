# DESIGN.md - C2C Games Design Token & UI Specification

## 1. Overview
The C2C Games interface uses a night-festival dark aesthetic (plum-black canvas with rose-pink neon accents) inside a compact window card.

## 2. Color Tokens

```yaml
colors:
  canvas: "#100913"
  cardBg: "#1a0d18"
  cardBorder: "rgba(235, 110, 160, 0.28)"
  rosePrimary: "#ea578c"
  roseGlow: "rgba(234, 87, 140, 0.45)"
  textPrimary: "#fdf5f8"
  textMuted: "#b39aa6"
```

## 3. Layout Specs
- Window size: 470px x 640px
- Slider Strips: 3 vertical strips on left side (Hue, Saturation, Value)
- Stage Area: Center display showcasing dynamic SVG emblem facets
